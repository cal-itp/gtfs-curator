# gtfs-curator
Curated collections of GTFS data products.

This repository is home to Caltrans Division of Data & Digital Services
stable, mature and maintained GTFS data products.
Many started out in the [data-analyses](https://github.com/cal-itp/data-analyses)
repo. New data products will launch here as we aim to make the GTFS
schedule and real-time performance metrics publicly available.

## [Data Products](https://analysis.dds.dot.ca.gov) and [Reports site](https://reports.dds.dot.ca.gov/)

1. GTFS Digest (owner: [@amandaha8](https://github.com/amandaha8))
   - GTFS schedule + RT [operator](https://analysis.dds.dot.ca.gov/gtfs_digest/) summary
   - Caltrans [district](https://analysis.dds.dot.ca.gov/district_digest/)
   - legislative [district](https://analysis.dds.dot.ca.gov/legislative_district_digest/)

2. GTFS RT trip updates reports (owner: [@tiffanychu90](https://github.com/tiffanychu90))
   - RT [stop metrics](https://analysis.dds.dot.ca.gov/rt_stop_metrics/)
   - RT prediction accuracy [operator metrics](https://analysis.dds.dot.ca.gov/rt_operator_metrics/)

3. Future Roadmap: Consolidate all existing data products within GTFS Digest
   - existing 3 GTFS Digest products
   - GTFS RT trip updates
   - [reports](https://reports.dds.dot.ca.gov/)
   - expand with additional RT metrics, stop-level maps, etc
